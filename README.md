# CBR Design & Prototyping

This repository contains UX design prototypes, workflow explorations, and proof-of-concept implementations supporting Client Billing Registration (CBR) initiatives.

## Purpose

The goal of this repository is to support:

- UX design exploration
- Workflow validation
- Stakeholder demonstrations
- Requirements refinement
- Prototype testing
- Design-to-development collaboration

## Current Work

### EGWP Setup Prototype

The current prototype explores EGWP setup workflows, including:

- AR relationship management
- Carrier configuration workflows
- Fee setup and maintenance
- Review and validation experiences
- Process simplification opportunities

## Technology

This repository may include:

- HTML
- CSS
- JavaScript
- Static assets
- Prototype-specific documentation

## Notes

These artifacts are intended for demonstration, design validation, and requirements discovery purposes.

Some workflows, business rules, and data have been simplified or anonymized.
